# Сервис планирования поездок на общественном транспорте

## Назначение
Консольное приложение для планирования поездок на общественном транспорте.
Позволяет проверить доступность маршрута, рассчитать время в пути
и стоимость проезда, а также сформировать сводку о поездке.

## Целевая аудитория
Городские жители и туристы, пользующиеся общественным транспортом
(автобус, трамвай, метро) для ежедневных и разовых поездок.

## Предметная область
Городские пассажирские перевозки: маршруты, остановки, расписание,
расчёт времени поездки и стоимости проезда.

## Основные сущности
- Пользователь (пассажир)
- Маршрут
- Остановка
- Поездка

## Основные функции
- Проверка доступности маршрута между остановками
- Расчёт примерного времени поездки
- Расчёт стоимости проезда для пассажира
- Формирование сводки о поездке

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
