# Сервис планирования поездок на общественном транспорте

Консольное приложение для планирования поездок и учёта маршрутов.

## Возможности
- просмотр и поиск маршрутов;
- отбор по цене и сортировка;
- статистика по маршрутам;
- проверка доступности маршрута на дату;
- создание и отмена поездок;
- сохранение данных в JSON.

## Структура проекта
- `main.py` — точка запуска и меню;
- `routes.py` — работа с маршрутами;
- `trips.py` — работа с поездками;
- `storage.py` — сохранение/загрузка JSON;
- `utils.py` — ввод с обработкой ошибок;
- `data/` — JSON-файлы данных;
- `tests/` — автотесты pytest.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    pytest

## Проверка качества кода

    flake8
