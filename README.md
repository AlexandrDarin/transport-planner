## Веб-версия (Django)

### Запуск
    python manage.py migrate
    python manage.py runserver

Откройте http://127.0.0.1:8000/

### Страницы
| URL | Что показывает |
|---|---|
| `/` | главная с навигацией |
| `/routes/` | список маршрутов |
| `/routes/<id>/` | информация о маршруте |
| `/trips/` | список поездок |
| `/trips/<id>/` | информация о поездке |

При отсутствии маршрута или поездки возвращается страница с кодом 404.

### Технологии
- Django 5.2
- Bootstrap 5.3 (CDN)
- JSON-данные ПР3 (`models/`, `storage.py`)

### Структура
- `transport_planner/` — настройки Django-проекта
- `homepage/` — главная страница и общий каркас (`page()`)
- `routes_app/` — страницы маршрутов
- `trips_app/` — страницы поездок
- `models/` — классы ПР3 (`User`, `Route`, `Stop`, `Trip`)
- `data/` — JSON-файлы
- `main.py` — консольная версия (работает параллельно)
