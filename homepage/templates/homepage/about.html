О проекте

Сервис планирования поездок на общественном транспорте. Проект объединяет маршруты, остановки, пассажиров и поездки.

Технологии

  • Python и Django (шаблоны DTL, именованные URL, static)
  • SQLite и параметризованные SQL-запросы (модуль sqlite3)
  • Bootstrap 5 и собственные CSS / JavaScript
  • JSON-данные сохранены для консольной версии
